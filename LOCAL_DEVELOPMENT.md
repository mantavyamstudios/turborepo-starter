# Local Development (no API keys required)

This repo is [next-forge](https://github.com/vercel/next-forge) with a small set
of changes so the whole monorepo runs locally **without any third-party API
keys**. Every integration stays disabled until you add its key.

## Prerequisites

| Tool | Install | Why |
| --- | --- | --- |
| Node.js 20+ | `brew install node` | Runtime for tooling |
| Bun 1.3+ | `brew install oven-sh/bun/bun` | Package manager (repo pins bun) |
| PostgreSQL 15+ | `brew install postgresql@15 && brew services start postgresql@15` | Local database |
| Mintlify CLI | `npm i -g mintlify` | Runs `apps/docs` |
| Stripe CLI *(optional)* | `brew install stripe/stripe-cli/stripe` | Only for local Stripe webhooks |

## First-time setup

```sh
bun run setup:local
```

This creates the env files from each `.env.example` (empty keys commented out),
creates the `next_forge` database, installs dependencies and applies migrations.
Override the database with `DB_NAME=my_db bun run setup:local` or
`DATABASE_URL=postgresql://... bun run setup:local`. Existing env files are never
overwritten.

## Run everything

```sh
bun run dev:local
```

| URL | App |
| --- | --- |
| http://localhost:3000 | `apps/app` — main SaaS app (sign-in/sign-up) |
| http://localhost:3001/en | `apps/web` — marketing site |
| http://localhost:3002/health | `apps/api` — API, webhooks, cron |
| http://localhost:3003 | `apps/email` — React Email previews |
| http://localhost:3004 | `apps/docs` — Mintlify docs |
| http://localhost:3005 | `apps/studio` — Prisma Studio |
| http://localhost:6006 | `apps/storybook` — design-system components |

`dev:local` differs from `dev` in two ways:

- `--filter=!@repo/cms` skips the BaseHub type watcher, which exits without
  `BASEHUB_TOKEN`.
- `--continue` keeps the other apps running when one task fails (e.g. the
  `stripe listen` process in `apps/api` without the Stripe CLI).

Once all keys are configured, plain `bun run dev` works as upstream intends.

## Behaviour without keys

| Integration | Env var(s) | Without key |
| --- | --- | --- |
| Clerk (auth) | `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY` | **Keyless mode**: Clerk auto-creates a temporary dev instance (stored in gitignored `apps/*/.clerk/`). Sign-up works. See known issues. |
| Postgres | `DATABASE_URL` | Required. Local URL uses the `pg` adapter; any other URL uses Neon. |
| BaseHub (CMS) | `BASEHUB_TOKEN` | Blog/legal show "CMS content unavailable"; toolbar hidden. |
| Svix (webhooks) | `SVIX_TOKEN` | `/webhooks` shows "Webhooks not configured". |
| Stripe | `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | Payment webhooks respond "Not configured". |
| Liveblocks | `LIVEBLOCKS_SECRET` | Live cursors/avatars hidden. |
| Knock | `KNOCK_*` | Notifications feed hidden. |
| Resend, Arcjet, BetterStack, PostHog, GA, Upstash, Vercel flags | see `.env.example` files | Disabled / no-op. |

## Known issues (keyless mode only)

- **Hydration warning** ("A tree hydrated but some attributes… didn't match") on
  pages using Radix components (menus, dialogs). Cause: Clerk keyless mode wraps
  the app in an extra client-only component, shifting React `useId` values.
  Verified to disappear once Clerk keys are set. Fix: add free Clerk
  development keys from https://dashboard.clerk.com.
- **Sign-in shows a 401 in the console**: Clerk's unauthenticated handshake;
  expected.
- **Dashboard shows "No organization selected"** until you create an
  organization via the sidebar switcher.
- Sidebar entries other than *Webhooks* are upstream placeholders (`#` links).
- `apps/docs` is Mintlify's sample content; some of its links point to pages it
  doesn't include.

## Changes from upstream next-forge

| File | Change | Why |
| --- | --- | --- |
| `packages/database/index.ts` | Use `@prisma/adapter-pg` for localhost URLs | Local Postgres has no Neon websocket proxy |
| `packages/database/prisma.config.ts` | Load `packages/database/.env` via dotenv | Prisma 7 no longer auto-loads `.env` |
| `bunfig.toml` | Publicly hoist the `pg` dependency family | Next externalizes `pg`; its deps must resolve from app roots |
| `packages/cms/components/{toolbar,feed}.tsx` | Render nothing / a notice without `BASEHUB_TOKEN` | BaseHub components throw without a token |
| `apps/app/app/(authenticated)/{page,search/page,webhooks/page}.tsx`, `components/empty-state.tsx` | Empty states instead of 404 / thrown error | Missing org or `SVIX_TOKEN` previously 404'd or crashed |
| `package.json` | `setup:local`, `dev:local` scripts | Key-free local workflow |
| `scripts/setup-local.sh` | Env + DB bootstrap | Reproducible setup |
| `apps/docs/docs.json` | Generated by current Mintlify CLI from `mint.json` | Newer CLI format |
| `packages/database/prisma/migrations/` | Initial migration for the stub `Page` model | Replace when the real schema lands |

## Pulling upstream updates

The `upstream` remote points at `vercel/next-forge`:

```sh
git fetch upstream --tags
git merge v6.x.y        # merge a release tag; resolve conflicts, then test
```

The official `npx next-forge update` also works, but it copies upstream
files over yours. Review `git diff` afterwards and restore your changes.
